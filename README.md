# 📊 Data Jobs Dashboard | Power BI Portfolio Project

**From Learning Core Power BI Skills to Building a More Practical Dashboard**

## 📌 Project Overview

This project explores the data job market through interactive Power BI dashboards, focusing on job demand, salary trends, job titles, employment types, and global job distribution.

The project is divided into two parts, reflecting my learning journey from following a guided tutorial to improving the dashboard with more advanced Power BI techniques.

### 🎯 Project Objectives

- Develop foundational skills in data transformation, modeling, and visualization using Power BI.
- Understand how to build interactive dashboards that communicate data insights effectively.
- Apply more advanced Power BI techniques to improve analytical flexibility, usability, and report design.

## 🚀 Project Development

### Part 1: Learning Core Power BI Skills

![Dashboard 1 Overview](Images/Dashboard_1_page_1.png)

📂 **Open project:** [Dashboard Part 1](./Dashboard_1/)

The first dashboard was developed by following an instructor-led tutorial. My primary goal was to understand the fundamental concepts and workflow involved in building an interactive Power BI report.

**Key Learning Areas**
- Dashboard Design
- Data transformation and shaping using Power Query.
- Basic data modeling and table relationships.
- Standard aggregations and core DAX concepts.
- Charts (Bar, Line, Area, Column)
- Map Visualizations for Geospatial Data
- Data visualization, KPI cards, and detailed data tables.
- Interactive filtering, bookmarks, page navigation, and drill-through functionality.

### Part 2: Improving the Dashboard for Practical Use

![Dashboard 2 Overview](Images/Dashboard_2.png)

📂 **Open project:** [Dashboard Part 2](./Dashboard_2/)

The second part focuses on extending the foundational knowledge from Part 1 and making the dashboard more flexible, analytical, and suitable for practical use.

**Key Development Areas**
- Advanced Dashboard Design
- Advanced Power Query transformations
- Star schema modeling.
- Explicit DAX measures using `CALCULATE` and filter context techniques.
- Dynamic visualizations using field and numeric parameters.
- What-if analysis and enhanced geospatial insights.
- Advanced filtering, cross-filtering, and report performance considerations.


## 🛠️ Tools & Technologies

- **Power BI Desktop** — Dashboard development and data visualization
- **Power Query** — Data extraction, transformation, and shaping
- **DAX** — Measures and analytical calculations
- **Data Modeling** — Relationships and star schema principles


## 💡 Key Takeaway

This project represents my progression in Power BI, from learning fundamental concepts through guided practice to exploring more advanced techniques for building flexible, interactive, and practical analytical dashboards.
